# Local solo sessions and replay — 2026-10-16
User requested the next 50 planned and implemented tasks with advance approval, including commit and local merge. No remote push.

Goal: a playable offline solo match with deterministic stationary bots, resumable local checkpoints, and inspectable action-by-action replay. Preserve hotseat and server-authoritative online play. This is an architectural extension with isolated core, archive, CLI and client adapters.

Chosen design: bounded candidate search reuses projectile simulation, scheduled in small batches by the client. Human controls blue (team 1); red is automated. Easy/normal differ by search budget; no bot movement or hidden advantages. Alternative analytic-only aiming misses terrain and wind; unbounded search stalls frames.

Replay wraps all local mutations, preserves exact float values and fails visibly at bounded recording limits. A checkpoint captures current state with no action history; replay retains history for inspection. SessionStore validates options and per-player velocities; v2 checkpoints retain motion and accept legacy v1 with zero velocities. Online sessions cannot save/load local authority. Replay playback replaces only the local view temporarily and restores the live runner on exit. Playback is action-by-action, not a real-time video editor.

Interfaces: BotPlanner.begin(runner,difficulty), step(budget), finished, command; static choose. Replay.surrender; recording_error String. ReplayPlayback.load_recording(recorder), runner,index,action_count,finished; step()->Dictionary; seek(index)->bool. ReplayArchive.load_verified adds recorder. SessionStore.save(path,runner,options,velocities={})->Error and load(path)->Dictionary. Client writes user://last_session.json and user://last_replay.json.

Boundaries: bot agent owns core/bots and bot tests; replay agent owns core/replay and archive tests; tools agent owns shared/config, server/simulation_cli, utility help, tools and user docs; root owns client and integration tests. No protocol changes required. All features tested headless, native rendered UI inspected, whole suite plus independent review before commit.
