# Replay Studio Implementation Plan

> Execute with tests and independent review; user preapproved implementation.

**Goal:** Notes, verified clips, detailed comparison and portable archive bundles usable from existing inspector/library.
**Architecture:** Pure RefCounted models + one client coordinator, unchanged ReplayArchive/SessionStore.
**Tech Stack:** Godot4.6.2, ZIPReader/ZIPPacker, existing exact codec.
**Spec:** ../specs/2026-10-19-next-250-design.md

## Constraints and review focus

No source overwrite, traversal or symlink following; ZIP max20entries, max32MiB perentry, max64MiB total, max21members. Notes max200, text2000/title80; fingerprint64hex. All filesystem fixtures canonical temporary paths. Cancel/replay replacement must invalidate callbacks. Empty/EOF clip ranges rejected. Different initial configurations must be displayed honestly. Invalid bundle imports rollback every newly written file.

## Files and contracts

- `core/replay/replay_notebook.gd`: `bind(fingerprint,count)`, `add(index,title,body,category)`, `edit(id,patch)`, `remove(id)`, `list(query='',category='')`, `encode`, `decode(payload,fingerprint,count)`, `merge(payload)`, `load_from(path)`, `save_to(path,replace=true)`. All mutators Dictionary(ok,reason,id); private rows copied. IDs32hex; schema1 explicit fields; counter/index integer strict even JSONfloat.
- `core/replay/replay_clip_job.gd`: `begin(recording,start,end)->bool`, `step(budget=32)->Dictionary`, `cancel`, fields index/finished/error/result_recorder/result_runner. Reconstruct source prefix, capture atstart then execute/record original actions throughend. MAX4096 perstep. `notebook_for_clip` remaps source markers to new fingerprint.
- `core/replay/replay_diff.gd`: `compare(first_recorder,second_recorder,limit=256)->Dictionary` validates and replays privately, compares state/players/inventory/statistics/terrain and firstaction. `export(path,report,replace)` atomically writes schema1 with protectedinputpaths supplied byCLI.
- `core/storage/archive_bundle.gd`: `export_bundle(library,ids,path,replace=false)`, `inspect(path)`, `import_bundle(library,path)` with strict bounded ZIP names/manifest SHA. Preserve exact envelopepayload, reassignID throughverified library; rollback onfailure, avoid overwriting library/preferences.
- `client/session/replay_studio.gd`: `new(scene,notes_path='user://replay_notes')`, `setup`, `on_opened`, `update(delta)`, `closing_replay`. Tabs/fields/buttons in existing panels; FileDialog actions snapshotted token+fingerprint; cancel onhide. Root hooks afterarchive_ui setup, open/return andupdate. Public controls testable. Crossworkflow guards preserveonline and live.
- `server/replay_studio_cli.gd`: standalone executor consumes validated flags; rootGameConfig/main/utilitydispatch for clip-replay/diff-replays/verify-bundle.
