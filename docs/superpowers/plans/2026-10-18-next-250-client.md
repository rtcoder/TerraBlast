## Training (16–38)
core/training/training_lessons.gd: static list()->Array[Dictionary]; static get_lesson(id:String)->Dictionary. Fixed IDs movement,jump,cancel_aim,accuracy,power,wind,weapons,safe_fire,blind_accuracy,streak,ammo_budget. Each description, criterion, optional required available weapons; unsupported lesson explicitly reports unavailable. No map edits/new assets.
core/training/training_session.gd extends RefCounted:
- active:bool; lesson_id:String; phase:String ('ready','armed','result','complete'); assistance:String ('full','partial','none'); elapsed_active:float; attempts:AttemptHistory
- begin(lesson_id:String,snapshot:Dictionary)->Dictionary; snapshot from existing SessionStore encode, contains runner/options/velocities. Store independent decoded clones, never mutate caller.
- arm()->bool; observe_motion(position:Vector3,velocity:Vector3,grounded:bool,accepted_jump:bool)->void; observe_intent(kind:String)->void
- before_shot(snapshot:Dictionary,command:RefCounted,demonstration:bool=false)->bool; scene invokes only after legal user intent and before recorder submit; failed submit discards pending attempt.
- after_shot(command:RefCounted,result:Dictionary,context:Dictionary)->void; context carries stable event identity generation/turn/revision, target position/id/team, actual assistance mode. Evaluate actual authoritative events. Demonstration never grants user progress.
- tick(delta:float,paused:bool)->void; retry_lesson()->Dictionary; retry_attempt()->Dictionary; summary()->Dictionary; exit()->void. Retry returns verified cloned snapshot to scene integration, no direct scene calls.
- Capture original live snapshot on entering training; scene switches to clone. Exit restores original runner/options/velocities. No nesting with replay, remote or projectile animation. New training actions do not extend replay format; existing recorder captures normal commands/motion.
- No artificial physics changes: training wind exercise reads current wind; accuracy target is existing living enemy; movement zones relative to initial position; weapons drawn from existing inventory.
- One training attempt allowed in armed; scene control guard disallows next shot in result. Continue explicitly arms next attempt. Training may pause timer at presentation result state via scene pause guard; no hidden mutations to rules.
core/training/attempt_history.gd: append(attempt:Dictionary)->bool (dedupe event ID, max50); entries()->Array; best()->Dictionary; streak()->int. Fields event_id,weapon,power,impact,distance,enemy_damage,friendly_damage,hit,demonstration. Counters exclude demonstration. Deterministic ranking hit then enemy_damage then distance, first wins tie.
core/training/training_coach.gd: begin(runner)->bool; step(budget=2)->void; suggestion()->Dictionary {ok,command?,reason?}; cancel(). Wrap existing BotPlanner, no edits to planner. Validate generation/turn/revision before exposing suggestion; Demonstrate uses existing recorder.submit only on explicit user action.
core/training/training_progress.gd: complete(id)->bool; is_complete(id)->bool; reset(); load_from(path)/save_to(path)->Error. Fixed allowed lesson IDs, version1, atomic file, max16KiB.
client/ui/training_panel.gd: setup(lessons,progress); signals lesson_requested(id),retry_requested,last_retry_requested,continue_requested,next_requested,coach_requested,demonstrate_requested,exit_requested,assistance_changed(mode); update_state(summary,hint)->void. Accessible scroll, no direct runner mutation.
Scene hooks: _open_training(id),_retry_training(last_attempt=false),_exit_training(),_update_training(delta),_on_training_result(command,result),_render_training_markers(). Hook submit result path once; coach submit calls same path with demonstration marker. Existing playback/library methods untouched.
