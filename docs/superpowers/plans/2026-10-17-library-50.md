# Biblioteka, powtórki i sterowanie — 50 zadań

Użytkownik zaakceptował z góry opracowanie, realizację, testy i lokalny commit/merge. Zakres: named checkpoint/replay library, timed playback, key remapping. Bez push.

## Projekt
Biblioteka przechowuje jednoplikowe, atomowo zapisywane koperty JSON w user://archive_library. ID niezależne od tytułu, max 100 wpisów, max 32 MiB pliku. Wnętrze używa istniejącego dokładnego kodeka float64; żadnego ładowania Resource z danych. Wybrano koperty zamiast dodatkowego indeksu, by uniknąć niespójności dwóch plików. Uszkodzone wpisy nie podmieniają bieżącego meczu.

Playback wykonuje oryginalne akcje w tej samej kolejności; tylko tick.delta wyznacza czas. Nie dzieli ticków, więc hash pozostaje identyczny. Seek odbudowuje runner z początkowego snapshotu, nie wprowadza cache wielkich światów. Budżet akcji ogranicza pracę klatki. Czas nie obejmuje wizualnej animacji pocisku.

Bindings to osobny walidowany plik; fizyczne klawisze, jawne konflikty, Escape i F-keys zarezerwowane. Strzałki pozostają aliasami. Capture poprzedza gameplay i globalne skróty. Ustawienia i biblioteka mają scroll przy HUD 125%.
