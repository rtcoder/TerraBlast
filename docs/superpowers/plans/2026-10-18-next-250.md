## Global Constraints
- Exact float64 replay hashes and legacy v1/v2 archives remain supported.
- No client authority, arbitrary resource loading, new external packages or remote production deployment.
- Tests use isolated temporary files; no mutation of normal user data.
- User authorized planning, implementation, commit and push in advance.

## Review Focus
- Oversized/malformed input must fail before expensive allocation or simulation.
- Late network callbacks must not mutate replacement sessions.
- Interrupted transfers and cancellation must preserve the last valid runner.
- UI focus/modal/capture must prevent accidental gameplay operations.
- Reports and export manifests must never execute commands or traverse paths from input files.
