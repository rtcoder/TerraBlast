## Design

Preserve server authority and pure core, current RMB aim/LMB charge controls, three weapon resources and local ten-player / network two-player defaults. Extend existing systems rather than replacing architecture. All simulation limits validated, terrain updates atomic, network snapshots self-describing. Local settings never affect authoritative rules. Debug tuning only available in local development. Reconnect uses an opaque server-issued token and bounded reservation.

## Work packages and acceptance
